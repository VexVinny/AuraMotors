Aplicação Python — Banco de Dados

Este repositório é destinado ao armazenamento e desenvolvimento da aplicação em Python, 
integrada ao banco de dados por meio de ODBC (Open Database Connectivity).

O projeto foi desenvolvido como parte da disciplina de Banco de Dados, 
do 3º período do curso de Ciência da Computação, tendo como objetivo aplicar, 
na prática, os conhecimentos relacionados à integração entre uma aplicação e um sistema de gerenciamento de banco de dados.

Neste repositório serão armazenados os códigos-fonte da aplicação, 
configurações e demais arquivos necessários para o desenvolvimento e execução do projeto.
